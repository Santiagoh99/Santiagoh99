I build web products that move money or book something: checkouts, ticket deposits, reservations and investment platform features. 5+ years shipping end to end, from the database to the interface, in production.

- **Santander Tecnología Argentina** — backend and frontend for the bank's client-facing investment platform: Node.js/NestJS microservices, microfrontends, GitLab CI/CD, OpenShift, Dynatrace. Now also Data Engineering (Hive, AWS, Power BI, Grafana).
- **Port St. Lucie SC** (USL League One, Florida) — remote, in English. I run the club's web properties: official site, online store, Soccer School site, stadium microsite and tournament registration with PayPal payments.
- **Atlantic Four Tech** — SaaS products for restaurants and sports venues.
- **Qubatio** — joined in November 2026.
